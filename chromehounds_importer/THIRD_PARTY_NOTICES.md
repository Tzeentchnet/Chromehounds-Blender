# Third-Party Notices

Chromehounds Importer is an independent interoperability project and contains
no game assets.

Implementation research used these MIT-licensed projects:

- `WarpZephyr/HoundTemplates`
  (<https://github.com/WarpZephyr/HoundTemplates>) for MDL4, SMD4, and MSB
  structure research.
- `WarpZephyr/FromAssimp`
  (<https://github.com/WarpZephyr/FromAssimp>) for model bind-space and
  bone-palette behavior research.
- ReGPU (<https://github.com/zer0ducksgiven/ReGPU>) for Xbox 360/Xenos
  texture fetch, tiling, endian, format, swizzle, and block-decoding behavior.
